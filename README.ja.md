# Prompt Picker

Prompt Picker は、大人向けの Windows アプリです。自分のライブラリからプロンプトを1つ引き、すでに使ったものを記録します。

## 機能

### プロンプトを引く

- レベルで絞り、除外と優先を付けて1つ引きます。
- 引いた内容をキャラクターに記録します。
- 元に戻す、やり直す、コピーができます。

### プロンプトデータ

- 追加、貼り付け、編集ができます。
- ラベルは絞り込みに使います。メモは説明用のタグで、カンマで分かれます。
- 検索と並べ替えができます。
- バックアップの書き出しと読み込みができます。

### プロンプトログ

- キャラクターごとに、使った行を残します。
- 追加日または引いた順で並べ替えます。
- 同じラベルの記録行をまとめて消せます。

### 設定

- 言語、文字サイズ、ショートカット、色を変更できます。
- 更新を確認し、変更点を読めます。
- バックアップ、リセット、アンインストールができます。

## インストール

最新のインストーラーは[リリースページ](https://github.com/linekoaiart129/prompt-picker-releases/releases/latest)からダウンロードします。

Windows が「Windows によって PC が保護されました」と表示したら、**詳細情報**、次に**実行**を選んでください。このアプリはコード署名されていません。SmartScreen とウイルス対策はオンのままにしてください。オフにしないでください。

## 更新

インストール済みのアプリが更新を確認し、新しい版をインストールします。プロンプトはこの PC に残ります。

## データとプライバシー

プロンプトと設定はこの PC にだけ保存されます。アップロードされません。
