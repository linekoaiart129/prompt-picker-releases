# Prompt Picker

Prompt Picker는 성인을 위한 Windows 앱입니다. 내 라이브러리에서 프롬프트 하나를 뽑고, 이미 쓴 항목을 기억합니다.

## 기능

### 프롬프트 뽑기

- 등급으로 뽑고, 제외와 우선순위를 쓸 수 있습니다.
- 뽑은 내용을 캐릭터에 저장합니다.
- 실행 취소, 다시 실행, 복사를 할 수 있습니다.

### 프롬프트 데이터

- 프롬프트를 추가하고, 붙여 넣고, 수정합니다.
- 라벨은 필터에 쓰입니다. 메모는 설명 태그이며 쉼표가 나눕니다.
- 검색하고 정렬합니다.
- 백업을 가져오거나 내보냅니다.

### 프롬프트 기록

- 캐릭터마다 이미 쓴 행을 남깁니다.
- 추가한 날짜 또는 뽑은 순서로 정렬합니다.
- 같은 라벨이 있는 기록 행을 지웁니다.

### 설정

- 언어, 글자 크기, 단축키, 색을 바꿉니다.
- 업데이트를 확인하고 변경 내용을 읽습니다.
- 백업, 초기화, 제거를 할 수 있습니다.

## 설치

[릴리스 페이지](https://github.com/linekoaiart129/prompt-picker-releases/releases/latest)에서 최신 설치 파일을 받습니다.

Windows에 “Windows에서 PC를 보호했습니다”가 나오면 **추가 정보**를 누른 다음 **실행**을 선택하세요. 이 앱은 코드 서명이 되어 있지 않습니다. SmartScreen과 백신은 켜 두세요. 끄지 마세요.

## 업데이트

설치된 앱이 업데이트를 확인하고 새 버전을 설치합니다. 프롬프트는 이 PC에 남습니다.

## 데이터와 개인정보

프롬프트와 설정은 이 PC에만 저장됩니다. 업로드되지 않습니다.
