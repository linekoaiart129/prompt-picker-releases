# Prompt Picker

Prompt Picker is a Windows app for adults. It draws one prompt from your own library and remembers what you have already used.

## Features

### Pick prompt

- Draw one prompt by level, with exclude and priority.
- Save it to a character.
- Undo, redo, and copy.

### Prompt Data

- Add, paste, and edit prompts.
- Labels are used for filtering. Notes are descriptive tags, and a comma separates them.
- Search and sort your library.
- Import and export a backup.

### Prompt Log

- Each character keeps the rows you already used.
- Sort by date added or by pick order.
- Clear logged rows that share a label.

### Settings

- Choose language, text size, shortcuts, and colors.
- Check for updates and read what changed.
- Back up, reset, or uninstall.

## Install

Download the latest installer from the [releases page](https://github.com/linekoaiart129/prompt-picker-releases/releases/latest).

If Windows says “Windows protected your PC”, choose **More info**, then **Run anyway**. The app is not code-signed. Leave SmartScreen and your antivirus on. Do not turn them off.

## Updates

The installed app checks for updates and installs the new version for you. Your prompts stay on this PC.

## Data and privacy

Prompts and settings are stored only on this PC. They are not uploaded.
