# Prompt Picker

Prompt Picker 是一款面向成年人的 Windows 应用。它从你自己的提示词库中随机抽取一条，并记住你已经用过的内容。

## 功能

### 抽取提示词

- 按等级抽取，并可以排除或优先某些标注。
- 把抽到的内容记到一个角色上。
- 可以撤销、重做和复制。

### 提示词数据

- 添加、粘贴和编辑提示词。
- 搜索和排序。
- 导入和导出备份。

### 提示词记录

- 每个角色保留已经用过的行。
- 按添加日期或抽取顺序排序。
- 清除带有同一标注的已记录行。

### 设置

- 选择语言、字号、快捷键和颜色。
- 检查更新并查看更改说明。
- 备份、重置或卸载。

## 安装

从[发布页](https://github.com/linekoaiart129/prompt-picker-releases/releases/latest)下载最新安装包。

如果 Windows 显示“Windows 已保护你的电脑”，请选择**更多信息**，然后选择**仍要运行**。此应用没有代码签名。请保持 SmartScreen 和杀毒软件开启，不要关闭它们。

## 更新

已安装的应用会自行检查并安装更新。你的提示词仍留在这台电脑上。

## 数据与隐私

提示词和设置只保存在这台电脑上，不会上传。
